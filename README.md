# Метеостанція на Raspberry Pi Zero W

Курсовий проєкт локальної метеостанції для вимірювання параметрів мікроклімату та відображення їх у веб-інтерфейсі.

## Функціонал
* Збір даних із датчиків у реальному часі:
  * температура повітря (°C);
  * відносна вологість (%);
  * атмосферний тиск (гПа та мм рт. ст.);
  * рівень освітленості (лк).
* Збереження історії вимірювань у базу даних.
* Перегляд поточних показників і графіків змін через браузер.

## Компоненти
* **Raspberry Pi Zero W** — основна плата.
* **BME280** — датчик температури, вологості та тиску.
* **BH1750 (GY-302)** — датчик освітленості.

## Технології
* **Python** — опитування датчиків і логіка сервера (`smbus2`, `RPi.bme280`, `Flask`).
* **SQLite** — локальна база даних.
* **HTML / CSS / Chart.js** — веб-інтерфейс і графіки.
